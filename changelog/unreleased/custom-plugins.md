### New

- **Plugins:** your own live blocks in the chat's right panel, made by an agent from a command you approve

  Ask an agent for a block such as "last prod deploys" and it proposes one: a command and how its result is laid out. Approve the exact command once, and the block appears under the agent cards in every chat in its folders. It refreshes while you look at it, Ask sends its data to the message box, and buttons can run commands. Settings → Plugins switches them, runs one now in a folder you pick, re-folders or deletes them.
