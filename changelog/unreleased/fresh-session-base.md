### New

- **Teams:** see what a member's new session already holds before it starts working

  The team page's new Fresh session section shows, per project, how many tokens a member's fresh CLI session started with in the team's recent runs, and how much of that is Geniro's instructions, the repository's instruction files and the CLI's own tools, MCP servers and plugins. A team analysis reads the same figures, so it can say what to trim. Parts the CLI does not report are marked "not measured".
