### Improved

- **Lessons:** a lesson that updates an agent's note you have not approved now applies by itself, as does moving such a note into the memory index. The card says it did, and Undo puts the old text back. Nothing applies by itself while you review agent writes, and your own and approved entries still wait for you. Settings → Memory now explains the Lessons list as lessons waiting for your decision.

### Fixed

- **Lessons:** applying a lesson no longer dead-ends when memory already holds a similar entry. Update, Save to memory and Edit now name the similar entries and let you press again to keep your change anyway, as Settings → Memory does.
