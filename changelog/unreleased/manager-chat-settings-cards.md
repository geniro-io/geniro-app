### New

- **Command center:** what waits for you in Settings also shows at the foot of the manager chat

  Agent updates and signed-out agent accounts, a Geniro update ready to install or restart into, shared links waiting for a storage sign-in and memory conflicts each show as a card with the same buttons Settings offers — Update, Sign in, Update now, Restart now, Sign in to the storage, Review conflicts — with no manager turn. A card goes away once its reason does, whether you settled it in the chat or in Settings. On a paired phone the Geniro update and the storage sign-in are shown without their buttons, since both run on the Mac. Each card also has **Dismiss**, which folds it to one line on this device; **Show** brings it back, and a card opens again by itself when something new appears in it.
