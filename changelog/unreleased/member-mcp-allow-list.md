### New

- **Teams:** load only the MCP servers a member needs

  On Claude, a team member or one of its pool members can load only the servers you pick, and a project can set its own list. Everything else stays out of its sessions, account connectors added later included, so Gmail, Calendar or Spotify stop filling every request. Leave out account connectors drops them in one click while keeping the ones the member uses.

### Improved

- **Fresh session:** see what Claude itself says a member's new session holds — system prompt, tools, skills, memory files and each MCP server — and a starting size read from the session's first request

### Fixed

- **Fresh session:** count the new sessions of every team member, including the ones it answers calls in, not only those of a member with a pool
