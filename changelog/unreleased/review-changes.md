### New

- **Review changes:** read a thread's changes as a diff and comment on them for the agent

  The changes chip now opens a full-window review: every changed file with line numbers, highlighting and marked words, more lines around each change on a press, and a Viewed tick per file that clears when the file changes again. Comment on a line, a range or a whole file, then send all your comments to the agent as one review — it waits for the agent's turn to end. The agent answers under each comment and marks it fixed or not fixed; you resolve it or reopen it. Comments stay in Geniro and never reach git or GitHub.
