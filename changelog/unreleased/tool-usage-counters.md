### New

- **Tools and capabilities:** see how often every tool, capability, skill and slash command is used, in Settings → System analysis

  Geniro counts the calls of its own tools, your CLIs' tools and other MCP servers' tools, and every Geniro capability, skill and slash command agents used — with errors, refusals, last use, average time and result size — and lists the tools and capabilities nobody has called. Only names and counts are kept, never what a tool was asked or answered. The system analysis reads these counts and can propose to improve, remove, merge or keep a tool, with the figures behind each proposal on its card.

### Improved

- The detailed tool log behind the Stats page's tool tables is kept 90 days by default; you can choose 30 days, a year or forever in Settings → System analysis
