### New

- **What's new:** after an update, Geniro shows what changed since the version you last saw

  The first launch after an update opens a short note: which version you came from, which one you are on now, and every new feature, improvement and fix in between as one list. Skipped a few updates? They are all in it, so nothing slips past you. Close it and it stays closed until the next update.

- **Settings → What's new:** the full changelog, with search, a filter by kind of change and a jump to any version

  Every Geniro release in one place, newest first, with the version you run marked. Search for a feature by name, show only fixes, or jump straight to a version to see when something arrived. It is built into the app, so it works offline.
